❓ PROBLEME?
═══════════════════════════════════════════════════════════════

Problem: "Python ist nicht installiert"
Lösung:  Installiere Python von https://www.python.org
         (Version 3.6 oder höher)

Problem: "tkinter nicht gefunden"
Lösung:
  • Ubuntu/Debian: sudo apt-get install python3-tk
  • Fedora: sudo dnf install python3-tkinter
  • Mac/Windows: Sollte schon installiert sein

Problem: "Nichts passiert beim Doppelklick"
Lösung:
  1. Rechtsklick auf START_HIER.py
  2. Wähle "Öffnen mit" → "Python"

  Oder nutze die Kommandozeile (siehe oben)
